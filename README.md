# CRUD Operations on Data Structures 🌳

This repository contains implementations of **CRUD (Create, Read, Update, Delete) operations** on different data structures using **C**.

The main goal of this assignment is to understand how different data structures work internally and how CRUD operations are implemented for each one, along with proper input handling and validations.

## 🛡️ Validations

A major part of this assignment is handling **invalid inputs and edge cases** instead of assuming that the user will always enter valid data.

The implementations include validations such as:

* Invalid menu choices
* Invalid numeric input
* Empty data structure operations
* Overflow and underflow
* Invalid array indexes
* Duplicate values where not allowed
* Searching for unavailable elements
* Deleting non-existing elements
* Invalid tree operations
* Memory allocation checks
* Boundary conditions
* Maximum input limits

The goal is to make every data structure **safe and reliable to use**.

## 🔄 CRUD Approach

For each data structure, I focused on understanding the basic CRUD operations:

**Create → Read → Update → Delete**

Along with additional operations required by the particular data structure, such as:

**Push → Pop → Peek** for Stack

**Enqueue → Dequeue** for Queue

**Insert → Search → Delete → Traverse** for Trees
